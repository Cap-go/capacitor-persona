Overview

Goal
Upgrade to Persona iOS Inquiry SDK 3.11.0 (and Android 2.59.1) with no breaking change to src/definitions.ts, released as 8.2.0.
Architecture
The plugin is a thin bridge. src/definitions.ts is the contract; PersonaPlugin.swift and PersonaPlugin.java translate startInquiry options into the native builder API and forward SDK callbacks as inquiryComplete, inquiryCanceled, and inquiryError events. Persona v3 removed InquiryConfiguration and typed the iOS error callback, so the iOS bridge switches fully to the builder API and gains a small, unit-tested error mapper. Everything else is a version pin, docs, and a drift guard.
Tech stack
Capacitor 8 plugin template (Bun, TypeScript 5.9, Rollup, @capacitor/docgen), Swift 5 language mode via SwiftPM tools 5.9 and CocoaPods, Java 21 Android library (AGP 8.13), GitHub Actions.
Spec
No separate spec. Requirements come from upstream issue #8, Persona's iOS v2 to v3 migration guide and iOS changelog, and the repo's AGENTS.md. The research table records every fact the plan relies on and how it was verified.
Execution
For agentic workers: use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans, one task at a time. The Markdown twin of this page lives at docs/superpowers/plans/2026-10-11-persona-sdk-v3-upgrade.md.

Global constraints

From AGENTS.md and the CI workflows. Every task's requirements include these.

  • Version follows the Capacitor major. The plugin stays on 8.x. This release is 8.2.0, produced by CI (capacitor-plugin-standard-version in bump_version.yml) from conventional-commit messages. Use feat: on at least one commit. Never use feat!: or a BREAKING CHANGE footer. Never hand-edit "version" in package.json or CHANGELOG.md.
  • No breaking changes in src/definitions.ts. Only JSDoc edits and additive optional fields.
  • Ship both CocoaPods and SPM. The podspec and Package.swift must resolve Persona at the same version.
  • capacitor-swift-pm stays pinned from: "8.0.0"; the guard_swiftpm_version CI job fails otherwise.
  • iOS deployment target stays 15.0 in both manifests (Persona 3.x needs exactly that).
  • Bun for everything. bun install, bun run, bunx. Never npm.
  • Java 21 only for Android. compileSdk 36 and minSdk 24 stay.
  • README API section is generated. Never edit between the docgen markers; edit src/definitions.ts and run bun run build.
  • Formatting: bun run fmt before every commit. CI runs bun run lint.
  • Timeouts: new CI steps stay inside each job's existing 10-minute cap.
  • Commit style: lower-case conventional commits as in the git log (feat(ios):, fix(ci):, docs:). No Jira prefixes in this repo. End every message with Co-Authored-By: Claude Fable 5.1 <noreply@anthropic.com>.
  • Behaviour matches on both platforms unless the SDK makes that impossible; differences go in JSDoc.
  • No push. The author has no write access to Cap-go/capacitor-persona and has not forked it yet. Every task commits locally only; the plan stops after local verification in Task 7. Pushing and the PR happen later, from a fork, outside this plan.

Review focus

Input classes the SDK change touches that automated tests do not fully exercise. Each names the task that owns its check.

  1. inquiryError with .misconfigured(...) on iOS. A bad templateId must yield a readable error, errorCode: "misconfigured", and a cause with the detail, not a generic "operation couldn't be completed" string. Pinned by the XCTest in Task 3.
  2. templateVersion together with locale on iOS. Previously rejected on iOS only; must now launch. Pinned by the example-app check in Task 7 and the JSDoc change in Task 4.
  3. inquiryId together with environment on iOS. Must still reject with the existing message, since v3's InquiryBuilder has no environment setter and Android rejects it too. Pinned by Task 7.
  4. CocoaPods consumers. pod install must resolve PersonaInquirySDK2 3.11.0 (3.x pods exist only from 3.8.0). Pinned by the pod lint in Task 2 and the drift guard in Task 6.
  5. Older Xcode. The 3.11.0 Swift interface was emitted by Swift 6.3.2 and is verified only with Xcode 26.2 (local) and 26.6 (CI). Pinned by the README statement in Task 5 and CI's iOS job in Task 7.

  3. Implement the mapper

    Create ios/Sources/PersonaPlugin/PersonaErrorMapper.swift:

    import Foundation
import Persona2

/// Translates Persona's typed `PersonaError` into the `inquiryError` event payload.
///
/// Keys mirror `InquiryErrorInfo` in `src/definitions.ts`. `errorCode` values are the
/// `PersonaError` case names so JavaScript can switch on them; Android emits its own
/// SDK enum names, which is documented in `definitions.ts`.
enum PersonaErrorMapper {
    static func code(for error: PersonaError) -> String {
        switch error {
        case .networking:
            return "networking"
        case .invalidSessionToken:
            return "invalidSessionToken"
        case .oneTimeLinkCodeInvalid:
            return "oneTimeLinkCodeInvalid"
        case .rateLimitExceeded:
            return "rateLimitExceeded"
        case .camera:
            return "camera"
        case .gps:
            return "gps"
        case .permissions:
            return "permissions"
        case .misconfigured:
            return "misconfigured"
        case .other:
            return "other"
        @unknown default:
            return "unknown"
        }
    }

    static func payload(for error: PersonaError) -> [String: Any] {
        var payload: [String: Any] = [
            "error": error.debugDescription,
            "errorCode": code(for: error)
        ]

        if case .misconfigured(let configurationError) = error {
            payload["cause"] = configurationError.localizedDescription
        }

        return payload
    }
}

    @unknown default is required: Persona2 is built with library evolution, so PersonaError is non-frozen and Swift warns on an otherwise-exhaustive switch.

    ## iOS setup

1. Run `npx cap sync ios`.
2. Ensure the iOS deployment target is **15.0** or newer (matches the plugin podspec and `Package.swift`).
3. Build with **Xcode 26.2 or newer**. Persona 3.x ships as a binary XCFramework whose Swift interface is produced by a current Swift 6 toolchain; older Xcode releases are not verified.
4. Add usage descriptions to `ios/App/App/Info.plist`. Persona requires camera and location strings for every template, and microphone when a template records video:

```xml
<key>NSCameraUsageDescription</key>
<string>We use the camera to verify your identity.</string>
<key>NSLocationWhenInUseUsageDescription</key>
<string>We use your location during identity verification.</string>
<key>NSMicrophoneUsageDescription</key>
<string>We use the microphone when a verification records video.</string>
<key>NSBluetoothAlwaysUsageDescription</key>
<string>We use Bluetooth during identity verification when required.</string>
```

    #!/usr/bin/env node
/**
 * Persona SDK pin guard.
 *
 * Fails when Package.swift and the podspec disagree on the PersonaInquirySDK2 version,
 * which happens when a dependency bot updates one manifest but not the other.
 *
 * Usage:
 *   node scripts/check-persona-sdk-pin.mjs
 *   node scripts/check-persona-sdk-pin.mjs --dir path/to/plugin
 */

import { readFileSync } from 'node:fs';
import path from 'node:path';

function parseArgs(argv) {
  const out = { dir: process.cwd() };
  for (let i = 2; i < argv.length; i++) {
    if (argv[i] === '--dir') out.dir = path.resolve(argv[++i] || '.');
  }
  return out;
}

const { dir } = parseArgs(process.argv);

const packageSwift = readFileSync(path.join(dir, 'Package.swift'), 'utf8');
const podspec = readFileSync(path.join(dir, 'CapgoCapacitorPersona.podspec'), 'utf8');
const gradle = readFileSync(path.join(dir, 'android', 'build.gradle'), 'utf8');

const spmVersion = /inquiry-ios-2\.git"\s*,\s*exact:\s*"([^"]+)"/.exec(packageSwift)?.[1];
const podVersion = /s\.dependency\s+'PersonaInquirySDK2'\s*,\s*'([^']+)'/.exec(podspec)?.[1];
const androidDefault = /personaInquiryVersion\s*=\s*project\.findProperty\('personaInquiryVersion'\)\s*\?:\s*'([^']+)'/.exec(gradle)?.[1];

const errors = [];
if (!spmVersion) errors.push('Package.swift: could not find an exact: pin for inquiry-ios-2');
if (!podVersion) errors.push("podspec: could not find s.dependency 'PersonaInquirySDK2', '<version>'");
if (!androidDefault) errors.push('android/build.gradle: could not find the personaInquiryVersion default');
if (spmVersion && podVersion && spmVersion !== podVersion) {
  errors.push(`iOS pins differ: Package.swift=${spmVersion} podspec=${podVersion}`);
}

if (errors.length) {
  console.error('[persona-pin] FAIL');
  for (const e of errors) console.error(`- ${e}`);
  process.exit(1);
}

console.log(`[persona-pin] OK iOS PersonaInquirySDK2 ${spmVersion}, Android com.withpersona.sdk2:inquiry default ${androidDefault}`);
